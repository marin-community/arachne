# Local dogfood: 2026-10-02

This pass implements the Track/Thread distinction, improves the coordinator and
worker workflow, and drives the native app against local Loom. It does not claim
that every narrative in [user-scenarios.md](user-scenarios.md) is complete.

## Implemented

- User-facing **Track** naming; **New thread** for one-offs and metadata-only
  **Convert to track**, preserving conversation and checkout. Legacy roots stay
  Tracks; existing Loom API names/tags remain compatible.
- Separate Tracks and Threads navigation; inspector delegation opens a worker
  launch form; workers remain directly addressable. Command search and keyboard
  navigation cover metadata, PRs, branches, and archived sessions.
- Actionable attention reasons, local notification dismissal, compact in-app
  banners, and open human Todos in Home's Needs You with revision-checked
  completion and Track/project scoping.
- Review as an inspector tab; file filtering/completion; agent review and
  preparation requests; small local checkout edits with line numbers, wrapping,
  indentation, Cmd/Ctrl+S, restored drafts, and stale-content checks. Local
  landing rejects uncommitted source edits rather than silently omitting them.
- Preparation explicitly names the worker's same-repository coordinator target,
  distinguishes preparation from verified readiness, and reports remaining dirty
  files as incomplete. It does not automatically integrate, land, push, or open PRs.
- Activity shows existing Loom channels, delivery records, and event/timer watches
  without advancing message read markers. Delivery is distinct from handling.
- Saved Loom server profiles with credentials scoped per URL, connection failure
  recovery, server-scoped launch drafts/defaults, repository and branch completion,
  and project launch defaults. Absolute local launch paths use Loom's `cwd` field.
- Event subscriptions cover all live sessions in bounded streams, coalesce bursts,
  resync after reconnect, and cancel old streams. Server switching fences old
  events; rapid navigation cannot replace a newer conversation subscription.

All changes are in Arachne. Loom source was not changed or its server restarted.
Future Loom additions must remain generic; Arachne owns Track semantics and UI
policy.
